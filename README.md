# Реализация паттернов проектирования на Java

Проект демонстрирует реализацию 6 паттернов проектирования.

##  Реализованные паттерны


*Builder `model` | Пошаговое создание сложных объектов (Notification) 
*Strategy `strategy` | Выбор алгоритма отправки уведомлений (Email, SMS, Telegram) через HashMap 
*Chain of Responsibility `chain` | Последовательная обработка уведомлений (валидация → логирование) 
*Decorator `decorator` | Динамическое добавление функциональности (шифрование) 
*Adapter `adapter` | Адаптация старого SMS-шлюза к современному интерфейсу 
*Proxy `proxy` | Контроль доступа с ограничением скорости отправки (Rate Limiting)
